⚠ Security warnings on first launch

This app is not signed with a paid certificate. Your OS may show a security warning the first time you open it. This is normal for open-source tools — the app is safe.

🪟 Windows — "Windows protected your PC"

Click More info → Run anyway. Only needed once.

🍎 macOS — "app is damaged and can't be opened"

Open Terminal and run:

xattr -cr /Applications/CraftingEditor.app

Or: right-click the app → Open → Open again in the dialog.
